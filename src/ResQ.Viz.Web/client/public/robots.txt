# ResQ Viz — https://viz.resq.software
#
# Mirrors the resq.software apex origin policy.
#
# `Content-Signal:` lines are the AIPREF / Content Signals mechanism for
# declaring AI-usage preferences (https://contentsignals.org). They are emitted
# BARE rather than `#`-commented so Content-Signal-aware crawlers actually
# detect them; RFC 9309 §2.2.4 requires crawlers to IGNORE unrecognized lines,
# so they are a safe no-op for bots that don't understand them.
#
# Hybrid policy:
#   default `*`            : search=yes, ai-train=no,  ai-input=no  (conservative)
#   AI training crawlers   : search=no,  ai-train=no,  ai-input=no  (full opt-out)
#   AI realtime crawlers   : search=yes, ai-train=no,  ai-input=yes (preserve
#                            visibility in ChatGPT / Claude / Perplexity fetches)
#
# Unlike the apex site, `/assets/` is deliberately NOT disallowed. The viz is a
# client-rendered WebGL app: blocking its JS/CSS chunks would leave Googlebot
# rendering a blank canvas. Only non-content surfaces are blocked — the REST
# API, the SignalR hub, and the Cloudflare edge path.
#
# Note: this file is the *origin* policy. If Cloudflare's "Managed robots.txt"
# toggle is ON for this zone, Cloudflare serves its own robots.txt at the edge
# and this file is decorative.
#
# Canonical user-agent strings:
#   OpenAI       https://platform.openai.com/docs/bots
#   Anthropic    https://support.anthropic.com/en/articles/8896518
#   Google AI    https://blog.google/technology/ai/an-update-on-web-publisher-controls/
#   Perplexity   https://docs.perplexity.ai/guides/bots
#   Apple        https://support.apple.com/en-us/119829
#   Common Crawl https://commoncrawl.org/ccbot
#   ByteDance    https://www.useragentstring.com/Bytespider.php
#   Amazon       https://developer.amazon.com/amazonbot
